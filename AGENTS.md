# CodeMate migration scope

The user authorizes ONLY the Android stack migration to React Native, Expo and
TypeScript. The original `grok-workspace.zip` in the private CodeMate backup is the immutable source of truth. Production file hashes are recorded in `scripts/baseline-checksums.json`.
Preserve the interface, labels, dimensions, colours, controls and interactions.
In particular retain direct dragging across elements, eight resize handles,
content movement, the compact movable floating editor, one active More control,
font search and weights, continuous colour selection, exact HEX and eyedropper.
Do not add a move button or substitute controls. Do not implement the older
handover's correction list or later roadmap features. Ask before accepting a
necessary user-visible difference. Never describe native interactions as verified
without running them on an Android device or emulator.
